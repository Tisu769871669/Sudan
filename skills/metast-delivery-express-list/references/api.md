# Metast 快递公司列表接口

- Method：`GET`
- Base URL：`https://lx.metast.cn`
- Path：`/app-api/mcp/api-mcp/deliveryExpressList`
- 必需请求头：
  - `mcpKey`
  - `mcpSecret`

脚本需要的环境变量：

- `METAST_MCP_BASE_URL`
- `METAST_MCP_KEY`
- `METAST_MCP_SECRET`
